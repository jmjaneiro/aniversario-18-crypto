## 🚀 Como Colocar no Teu GitHub Pages (Passo a Passo Rápido)

Como a tua conta no GitHub é **`jmjaneiro`**, o link final recomendado será:
`https://jmjaneiro.github.io/aniversario-18-crypto/`

### 1. Criar o repositório no GitHub
1. Vai a [github.com/new](https://github.com/new).
2. Nome do repositório: `aniversario-18-crypto` (ou outro nome da tua preferência).
3. Mantém como **Público** (necessário para GitHub Pages gratuito).
4. Clica em **Create repository**.

### 2. Publicar a partir do terminal
No teu computador, abre o terminal nesta pasta (`/Users/joaojaneiro/Documents/Antigravity/aniversario-18-crypto`) e executa:

```bash
cd /Users/joaojaneiro/Documents/Antigravity/aniversario-18-crypto
git init
git add .
git commit -m "feat: lancamento landing page 18 anos bitcoin"
git branch -M main
git remote add origin https://github.com/jmjaneiro/aniversario-18-crypto.git
git push -u origin main
```

### 3. Ativar o GitHub Pages
1. No teu repositório no GitHub, vai a **Settings** > **Pages** (no menu lateral esquerdo).
2. Em **Build and deployment** > **Source**, seleciona **Deploy from a branch**.
3. Em **Branch**, escolhe `main` e a pasta `/ (root)`, e clica em **Save**.
4. Em cerca de 1 a 2 minutos, o site estará online no teu link:  
   👉 `https://jmjaneiro.github.io/aniversario-18-crypto/`

## 🖨️ Como Imprimir o Cartão QR Code para o Presente

1. Abre o ficheiro `index.html` no teu navegador (ou abre o link no GitHub Pages).
2. No canto superior direito, clica em **"🎁 Cartão QR do Presente"**.
3. Confirma o URL do teu GitHub Pages (o QR code é gerado instantaneamente).
4. Clica em **"🖨️ Imprimir Cartão de Oferta"**.
   - O estilo de impressão (`@media print`) oculta automaticamente o resto do site e formata apenas o cartão de luxo para caber perfeitamente numa folha ou papel cartão para recortar e meter na caixinha!
